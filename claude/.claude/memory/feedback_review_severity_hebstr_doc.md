Package-specific review dismissals for the `quarto-hebstr-doc` Quarto extension at `~/Documents/packages/quarto-hebstr-doc`, supplementing [[feedback_review_severity_personal]]. Distinct from [[feedback_review_severity_hebstr]] (the R package). See also [[reference_quarto_lua_shortcodes]], and `rules/lua.md` for the Lua gate.

**Why:** successive walkthroughs of `filters/filetree.lua` and `tests/test_filetree.lua` produced recurring idiom, performance and duplication findings that a future reviewer will re-flag; each was assessed and dismissed on the merits.

**How to apply (do NOT re-flag these):**
- **The 7-line `kw` helper duplicated between `filetree.lua` and `add-code-files.lua` is deliberate, not a refactor target.** Each shortcode is an autonomous entry point (CLAUDE.md calls them "autonomous"); factoring `kw` out costs a shared module plus a `package.path` derived from `PANDOC_SCRIPT_FILE` in each consumer, reopening the install-depth hazard CLAUDE.md already documents twice (filetree icons, and the Typst `code.tmTheme`, which went with the Typst format dropped on 2026-09-29 by `34e7003`, leaving the icons as the live example). ~20 lines of indirection + a new failure mode to save 7 stable lines. Rejected; the copies must stay byte-identical, so keep `kw` aligned across both.
- **The hardcoded `/` path separator is a deliberate single internal convention, not a `pandoc.path.join` omission.** `relpath` is the annotation-key AND display string; the sidecar is authored with `/` cross-platform, so `pandoc.path.join` (which emits `\` on Windows) would break key matching. `/` also works for filesystem access on all three OSes. Splitting the convention only for the FS-path joins would leave `relpath` on `/` two lines away, more confusing than uniform `/`. NOTED, no change.
- **No `list_directory` cache.** Measured 7 redundant listings of 66 on a depth-3 walk (each of 7 dirs listed twice: once to type via `classify`, once to read). Once-per-render, depth-bounded, OS dentry-cached; a cache is dead metadata by the premise test. NOTED.
- **The `warn` guard (`quarto and quarto.log...` + stderr fallback) vs the unguarded `quarto.doc.is_format` is intentional asymmetry.** `warn` is standalone-safe for helper testing; `is_format` has no non-quarto behavior and a nil-`quarto` crash there is already a clear error. The `project_dir = quarto and quarto.project...` guard is semantic (project legitimately absent in single-file render), a third distinct case, not part of the asymmetry. NOTED.
- **The local `kwargs()` helper of `tests/test_filetree.lua` mutating the table it is handed is not a defect.** It writes a default `annotations` into the caller's literal, and all 16 call sites pass a fresh literal (grepped 2026-09-29). The trap a reviewer names, a shared options table, is neutralised by the defect itself: the write is guarded by `== nil`, so a reused table gets the same value on the second call and the outcome is identical. A defensive copy has nothing to consume it. REJECTED 2026-09-29.
- **A zero-occurrence coercion edge case in the sidecar reader is NOTED, not fixed, unless it contradicts YAML itself.** A fractional `depth` is the worked example: measured 2026-09-29, the static render takes its ceiling (`2.1` already shows three levels) and the dynamic opening its floor, the two never disagreeing inside one mode, and no sidecar in use holds such a value. What earned a fix in that same pass, by contrast, was every case where the hand-rolled reader disagreed with a real YAML parser on the same file, since `read_sidecar` runs `pandoc.read` over it too: a trailing comment on an `exclude` item, a flow-mapping profile, a quoted profile name.
